# TURAN BOXING

Учебный одностраничный сайт боксёрского клуба на React, TypeScript, Tailwind CSS и Vite. Профили тренеров, отзывы, цены, расписание и контакты приведены для демонстрации. Форма проверяет поля в браузере. Сервер и база данных для заявок не используются.

## Локальный запуск

Используйте Node.js 22.12 или более позднюю версию ветки 22.x.

```sh
npm ci
npm run dev
```

## Production-сборка

```sh
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Настройки Vercel заданы в `vercel.json`. Переменные окружения для работы сайта не требуются.

После подключения репозитория к Vercel отправляйте проверенные изменения в ветку `main`. Vercel автоматически запустит новую сборку и обновит публичный сайт после её успешного завершения.
